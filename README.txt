Larpmaster

Larpmaster on Rajakatse Fantasia ry:n sovellus, jota käytetään yhdistyksen Rajakatse-fantasialarpeissa pelihahmojen numeeristen arvojen määrittämiseen. Modernisoidun version prototyypin on luonut Junior Turunen ja Lassi Janhonen.

Asennus

Vaiheet

1. Lataa Sovellus:
   - Lataa uusin julkaisu (Larpmaster) [Releases](https://github.com/jumppuu/larpmaster/releases) -sivulta.

2. Pura Tiedostot:
   - Pura ladattu zip-tiedosto haluamaasi sijaintiin tietokoneellasi.

3. Asenna .NET Runtime jos sinulla sitä ei ole

Mene kyseiseen linkkiin ja valitse .NET Desktop Runtime 8.0.11 ja asenna se.
https://dotnet.microsoft.com/en-us/download/dotnet/8.0

4. Aja Sovellus:
   - Avaa purettu kansio ja kaksoisnapsauta `Larpmaster` -tiedostoa ajaaksesi sovelluksen.

5. Windows saattaa ilmoittaa että sovellus on tuntematon ja ei ole turvallinen. Paina "Lisätietoja" ja "Suorita silti".

Käyttö

Uuden Hahmon Luominen

1. Avaa Sovellus:
   - Aja `Larpmaster.exe`.

2. Valitse Hahmon Luonti:
   - Valitse hahmosi rotu ja sukupuoli.

3. Luo Hahmon Ominaisuudet:
   - Käytä tilastojen luontiominaisuutta heittääksesi ja määrittääksesi tilastot hahmollesi.

4. Tallenna Hahmo:
   - Tallenna hahmoprofiili tulevaa käyttöä varten.
